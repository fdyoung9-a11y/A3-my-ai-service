# A3-my-ai-service

AI를 활용한 여행 추천 웹서비스입니다.  
사용자가 여행지를 입력하면 추천 문장을 생성해 보여줍니다.

## 프로젝트 소개

이 프로젝트는 HTML, CSS, JavaScript와 서버리스 API를 활용하여  
간단한 AI 여행 추천 서비스를 구현한 웹 애플리케이션입니다.

## 주요 기능

- 여행지 입력
- AI 여행 추천 결과 생성
- 블록형 UI 전환
- 반응형 웹 지원
- Vercel 배포

## 기술 스택

- HTML
- CSS
- JavaScript
- Python
- Vercel Serverless Function
